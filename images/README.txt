Drop pictures for entries in here, then point at them from amiga-data.js:

  { "id": "a500", ..., "image": "images/a500.jpg",
    "imageCredit": "Photo: …, CC BY-SA 2.5" }

Any entry without an "image" keeps its hand-drawn pictogram, and if a
picture ever fails to load the pictogram comes back — so a dead link can
never leave a broken frame on the page.

Landscape crops around 4:3 or 16:9 work best; the plate fills its frame.
